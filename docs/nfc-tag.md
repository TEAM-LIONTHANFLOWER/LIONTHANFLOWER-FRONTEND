# NFC 태그

매장 입구에 붙인 NFC 태그를 폰으로 찍으면 MCM Orbit 이 열리고, **그 매장이 어디인지 앱이 알고
시작합니다.** 고객은 주소를 칠 필요도, 앱을 설치할 필요도 없습니다.

기준일: 2026-09-09 · 관련 이슈: [#56](https://github.com/TEAM-LIONTHANFLOWER/LIONTHANFLOWER-FRONTEND/issues/56)

---

## 어떻게 동작하나요

태그 안에는 앱이 아니라 **주소 한 줄**이 들어 있습니다.

```
https://mcm-orbit.site/?store=MCM-SEOUL
```

폰을 태그에 대면 iOS·Android 가 알아서 이 주소를 엽니다. 브라우저가 배포된 웹을 띄우고,
진입 화면(`/`)이 `store` 쿼리에서 매장 코드를 꺼내 들고 로그인 화면으로 넘어갑니다.
`/login` 은 그 코드로 매장을 찾아 **"현재 고객님이 방문하신 매장은 [MCM 서울] 입니다"** 를
고객이 고른 언어로 보여 줍니다.

```
NFC 태그 (URL 레코드)
  └ 폰 OS 가 주소를 엶
      └ /?store=MCM-SEOUL   진입 화면이 코드를 읽어 store-tag-store 에 넣음
          └ /login          GET /api/stores 로 코드 → 매장명, 안내 문구에 표시
```

**앱이 NFC 를 직접 읽지 않습니다.** 읽는 쪽은 폰 OS 이고 우리는 주소만 받습니다.
그래서 `react-native-nfc-manager` 같은 네이티브 모듈도, 개발 빌드도 필요 없습니다 —
웹·iOS·Android·Expo Go 어디서 열어도 똑같이 동작합니다.

## 태그 굽는 법

우리 앱에는 태그 쓰기 기능이 없습니다. 시중 앱으로 한 번만 구우면 됩니다.

**준비물** — NTAG213 이상 NFC 스티커, NFC 가 되는 Android 폰(쓰기는 Android 가 편합니다),
[NFC Tools](https://play.google.com/store/apps/details?id=com.wakdev.wdnfc) (무료)

1. NFC Tools → **쓰기(Write)** → **레코드 추가** → **URL/URI**
2. 주소를 넣습니다 — `https://mcm-orbit.site/?store=<매장코드>`
3. **쓰기** 를 누르고 폰을 태그에 댑니다
4. 매장에 붙이기 전에 **쓰기 잠금(Lock)** 을 겁니다. 잠그지 않으면 누구나 덮어쓸 수 있고,
   잠근 태그는 되돌릴 수 없으니 주소를 한 번 더 확인하고 잠급니다.

> URL 은 반드시 `https://` 로 시작하는 전체 주소여야 합니다. `mcm-orbit.site` 처럼 스킴을
> 빼면 폰이 주소로 알아보지 못합니다.

### 매장 코드는 어디서 얻나요

`GET /api/stores` 가 돌려주는 `code` 값입니다. 브라우저에서 바로 확인할 수 있습니다.

```
https://mcmorbit.p-e.kr/api/stores?query=
```

`query` 를 비우면 전체 목록이 옵니다. 여기 있는 `code` 를 그대로 주소에 넣으면 됩니다.
직원 로그인(`/staff/login`) 의 `Working At` 검색이 쓰는 것과 같은 목록입니다.

## 확인하는 법

태그가 없어도 주소를 직접 열어 똑같이 시험할 수 있습니다.

| 열어 볼 주소                               | 기대하는 결과                                          |
| ------------------------------------------ | ------------------------------------------------------ |
| `/?store=<실제 매장코드>`                  | 스플래시 뒤 `/login` 안내 문구에 그 매장 이름이 뜹니다 |
| `/?store=NO-SUCH-STORE`                    | 이름을 못 찾아 코드 `NO-SUCH-STORE` 가 그대로 뜹니다   |
| `/` (쿼리 없이)                            | 지금까지와 같이 `MCM HAUS` 가 뜹니다                   |
| `/?store=A` 로 들어갔다가 다시 `/` 로 진입 | 앞서 찍은 `A` 가 남지 않고 `MCM HAUS` 로 돌아갑니다    |

이름을 찾는 동안(찰나입니다) 코드가 먼저 보였다가 이름으로 바뀝니다. 안내 한 줄 때문에 로그인
폼 전체를 로딩으로 가리지 않기로 한 결과이고, 코드가 그대로 남아 있으면 태그를 잘못 구웠거나
없는 매장이라는 뜻이라 매장에서 바로 알아볼 수 있습니다.

## 지금의 한계

- **서버는 고객이 어느 매장에서 들어왔는지 모릅니다.** 방문을 여는 `POST /api/customers/visits`
  가 매장을 받지 않아서, 매장 코드는 화면 표시용으로만 씁니다. 서버가 매장을 받게 되면
  `store-tag-store` 의 코드를 그대로 실어 보내면 됩니다.
- **앱을 껐다 켜면 코드가 사라집니다.** 영구 저장소를 아직 도입하지 않아 다른 전역 상태와
  같은 조건입니다 ([secure-store-impact.md](./secure-store-impact.md) 참고).
- **iOS 는 잠금 화면에서 태그를 읽습니다.** 별도 앱 없이 배너가 뜨지만, 저전력 모드이거나
  카메라가 켜져 있으면 읽지 않습니다. 기기 설정 문제라 앱에서 할 수 있는 일이 없습니다.
